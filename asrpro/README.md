# ASRPRO 语音模块（天问 Block）

ASRPRO 负责**离线**识别工人的语音指令，识别成功后：
1. 本地播报确认语（“已开始作业”等）；
2. 通过串口向哨兵 ESP32-C3 发送 4 字节命令帧 `AA 55 CMD SUM`（9600 8N1）。

哨兵收到后切换模式，并用 ESP-NOW 同步给所有锥桶。

## 命令词表

| ID | 命令词 | 播报 | CMD |
|---|---|---|---|
| 0 | 唤醒词：小哨兵 | 我在 | — |
| 1 | 开始作业 | 已开始作业，预警开启 | 0x01 |
| 2 | 结束作业 | 已结束作业 | 0x02 |
| 3 | 左侧封道 | 已切换左侧封道 | 0x03 |
| 4 | 右侧封道 | 已切换右侧封道 | 0x04 |
| 5 | 雨天模式 | 雨天模式已开启，预警距离加大 | 0x05 |
| 6 | 关闭雨天模式 | 雨天模式已关闭 | 0x06 |
| 7 | 夜间模式 | 夜间模式已开启 | 0x07 |
| 8 | 关闭夜间模式 | 夜间模式已关闭 | 0x08 |
| 9 | 报告电量 | （等待哨兵回复后播报） | 0x09 |
| 10 | 设备自检 | 开始自检 | 0x0A |
| 11 | （内部）电量正常 | 电量正常 | 回复 0x81 |
| 12 | （内部）电量不足 | 电量不足，请及时充电 | 回复 0x82 |

## 接线

| ASRPRO | 哨兵 ESP32-C3 |
|---|---|
| 串口 TX（板上丝印 TX） | GPIO20（UART0 RX） |
| 串口 RX（板上丝印 RX） | GPIO21（UART0 TX） |
| GND | GND（必须共地） |
| 5V | 5V |
| 喇叭 SPK+/SPK- | 4Ω 3W 小喇叭 |

> ASRPRO 不同版本串口引脚不同，请以你手上 ASRPRO V2.0 板子丝印和天问 Block “引脚说明”为准；PA0/PA1 可能用作晶振、部分引脚默认是下载口，避免占用。

## 使用步骤

1. 安装 **天问 Block**（官网 twen51.com 下载），选择设备 **ASRPRO**，模式选“代码编程”。
2. 新建工程，把 `asrpro_sentinel.c` 的内容粘贴进去（或按同样逻辑拖积木）。
3. 在“语音设置”中确认命令词、播报语、发音人。
4. 点击“编译下载”（首次需要生成模型，联网约 1–2 分钟）。
5. 说“小哨兵”唤醒，再说“开始作业”，听到播报、哨兵串口日志出现 `[VOICE] cmd=0x01` 即成功。
