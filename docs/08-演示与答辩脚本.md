# 演示与答辩脚本

## 1. 现场演示（5 分钟）

| 时间 | 动作 | 讲解要点 |
|---|---|---|
| 0:00 | 展示普通锥桶与智能锥桶并排 | “看起来一样，但它能看见来车。” |
| 0:30 | 对着 ASRPRO 说“小哨兵，开始作业”“左侧封道” | 离线语音，戴手套也能部署 |
| 1:00 | 同学手持遥控车 / 推车从远处快速接近（室内可用 L298N 语音小车） | 雷达测速测距 |
| 1:30 | 一级预警：流水灯向左流动 | 引导变道 |
| 2:00 | 继续靠近：二级预警，红色爆闪 + 蜂鸣，评委手上的工人报警器震动 | 工人撤离提醒 |
| 2:30 | 切到网页看板：实时曲线、事件列表、安全报告 | 数据化管理 |
| 3:30 | 说“雨天模式”，再次接近，展示更早触发 | 自适应阈值 |
| 4:00 | 总结成本与应用 | 哨兵物料估算约 115 元、即放即用；已验证与待验证分开讲 |

> 室内演示时雷达容易受墙面反射，提前把 `MIN_TRACK_SPEED` 调低、距离阈值调小并彩排；准备好户外实测视频作为备份。

## 2. 演示视频分镜（2～3 分钟）

1. **痛点（15 s）**：作业区新闻画面/示意动画 + 字幕“养护工人背对车流”。
2. **产品亮相（15 s）**：锥桶特写，灯头模块安装过程。
3. **语音部署（15 s）**：工人一句话开启。
4. **实测（60 s）**：电动车驶近，航拍或高处俯拍流水灯；画中画显示看板曲线。
5. **工人端（15 s）**：手环震动特写。
6. **数据（20 s）**：看板与安全报告。
7. **对比与成本（20 s）**：功能定位对比表；成本只说物料估算。
8. **结尾（10 s）**：口号“让每一个锥桶都成为哨兵”。

## 3. 答辩常见问题

**Q1：和太阳能爆闪灯有什么区别？**
爆闪灯一直闪，司机容易习惯性忽略；我们只在真正有危险车辆时按危险程度升级，并用流水灯给出方向，还同时提醒工人。

**Q2：雷达误报怎么解决？**
只追踪接近目标、最低速度过滤、角度和距离窗口、连续 3 帧确认；目标消失 1.5 s 才解除，避免闪断。实测误报率【待补充】，没测之前不报数字。

**Q3：为什么不用摄像头？**
雷达直接给出距离和速度，受光照影响小，算力要求低，也不拍人脸和车牌。雨雾中的实际表现还要实测。摄像头可以作为升级方向。

**Q4：ESP-NOW 可靠吗？距离多远？**
开阔地实测【待补充】m。设计上有预警期间 200 ms 重发、序号去重、两跳中继；联动锥桶 3 s 收不到刷新就回到黄闪，不会一直卡在报警状态。

**Q5：续航多久？**
3000 mAh 实测【待补充】小时。目标是覆盖一个工作日（≥ 8 h），能否达到要看实测。

**Q6：TTC 阈值怎么定的？**
5 s / 2.5 s 是设计初值，写在 `config.h`，还没有标定。下一步用封闭场地数据，在提前量和误报率之间调整。TTC 本身是交通冲突研究里常用的危险尺度（Hayward，1972）。

**Q7：如何落地推广？**
先做“改装灯头”，兼容现有锥桶；先找县乡公路或市政养护单位做封闭场地和小范围试用。【待补充：已联系的单位与反馈】

**Q8：与国家标准的关系？**
本系统是在 JTG H30—2015《公路养护安全作业规程》和 GB 5768.4—2017 要求的作业区布设之上的**附加主动提醒**，不替代标准要求的标志、锥桶和防撞设施。

**Q9：你们的核心技术难点是什么？**
低成本雷达数据的稳定化处理与多目标选择、自适应阈值、多节点低延迟同步、野外低功耗供电。

**Q10：下一步计划？**
先完成实物样机和封闭场地测试，用数据标定阈值；再做光照、雨量自动识别和多哨兵测减速度。

**Q11：和国外的入侵报警、顺序警示灯有什么不同？**
FHWA 的夜间作业区专题里已经有顺序警示灯和自动入侵报警这类做法。我们的不同是把 TTC 提前分级、流水灯、工人穿戴端和事件记录放进一个低成本节点。是否因此更早让司机减速，需要对比试验，我们还没有做。
