# 演示与答辩脚本

## 1. 现场演示（5 分钟）

| 时间 | 动作 | 讲解要点 |
|---|---|---|
| 0:00 | 展示普通锥桶与智能锥桶并排 | “看起来一样，但它能看见来车。” |
| 0:30 | 对着 ASRPRO 说“小哨兵，开始作业”“左侧封道” | 离线语音，戴手套也能部署 |
| 1:00 | 同学手持遥控车 / 推车从远处快速接近（室内可用 L298N 语音小车） | 雷达测速测距 |
| 1:30 | 一级预警：流水灯向左流动 | 引导变道 |
| 2:00 | 继续靠近：二级预警，红色爆闪 + 蜂鸣，评委手上的工人报警器震动 | 工人撤离提醒 |
| 2:30 | 切到网页看板：实时曲线、事件列表、安全报告 | 数据化管理 |
| 3:30 | 说“雨天模式”，再次接近，展示更早触发 | 自适应阈值 |
| 4:00 | 总结成本与应用 | 百元级、即放即用 |

> 室内演示时雷达容易受墙面反射，提前把 `MIN_TRACK_SPEED` 调低、距离阈值调小并彩排；准备好户外实测视频作为备份。

## 2. 演示视频分镜（2～3 分钟）

1. **痛点（15 s）**：作业区新闻画面/示意动画 + 字幕“养护工人背对车流”。
2. **产品亮相（15 s）**：锥桶特写，灯头模块安装过程。
3. **语音部署（15 s）**：工人一句话开启。
4. **实测（60 s）**：电动车驶近，航拍或高处俯拍流水灯；画中画显示看板曲线。
5. **工人端（15 s）**：手环震动特写。
6. **数据（20 s）**：看板与安全报告。
7. **对比与成本（20 s）**：与传统方案对比表。
8. **结尾（10 s）**：口号“让每一个锥桶都成为哨兵”。

## 3. 答辩常见问题

**Q1：和太阳能爆闪灯有什么区别？**
爆闪灯一直闪，司机容易习惯性忽略；我们只在真正有危险车辆时按危险程度升级，并用流水灯给出方向，还同时提醒工人。

**Q2：雷达误报怎么解决？**
只追踪接近目标、最低速度过滤、角度和距离窗口、连续 3 帧确认，实测误报率【填】。

**Q3：为什么不用摄像头？**
雷达全天候、不受光照和雨雾影响、成本低、没有隐私问题。摄像头可作为升级版，用于记录违规车辆。

**Q4：ESP-NOW 可靠吗？距离多远？**
开阔地实测【填】m；我们有重复广播、序号去重、两跳中继；联动锥桶即使收不到也会保持基础黄闪，不影响基本功能。

**Q5：续航多久？**
3000 mAh 实测【填】小时，覆盖一个工作日；可加太阳能板。

**Q6：TTC 阈值怎么定的？**
参考驾驶员感知-反应时间文献给出初值，再通过封闭场地实测标定，兼顾提前量和误报率。

**Q7：如何落地推广？**
先做“改装灯头”，兼容现有锥桶；面向县乡公路养护、市政养护单位试点；平台按年服务收费。

**Q8：与国家标准的关系？**
本系统是在现有作业区交通组织和安全设施基础上的**附加主动预警**，不替代标准要求的标志、锥桶和防撞设施。【可查阅并引用《公路养护安全作业规程》相关条款】

**Q9：你们的核心技术难点是什么？**
低成本雷达数据的稳定化处理与多目标选择、自适应阈值、多节点低延迟同步、野外低功耗供电。

**Q10：下一步计划？**
加摄像头抓拍超速车辆、光照雨量自动识别、多哨兵测减速度、与智慧公路平台对接。
