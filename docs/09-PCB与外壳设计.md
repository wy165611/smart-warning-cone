# PCB 与外壳设计

## 1. 原型阶段

先用**洞洞板 + 排母**焊接，ESP32-C3 SuperMini 插在排母上，方便替换。功能跑通后再画 PCB。

## 2. 嘉立创 EDA 画板要点

### 2.1 板子功能（哨兵/联动通用一块板，哨兵多焊雷达和 ASRPRO 接口）

| 区域 | 内容 |
|---|---|
| 主控 | ESP32-C3 SuperMini 排母（2×8） |
| 电源 | TP4056 充电电路（或直接用模块焊盘）、18650 座、5V 升压（可用 MT3608 电路或预留模块焊盘）、开关 |
| 雷达接口 | XH2.54 4P：5V / GND / TX / RX |
| ASRPRO 接口 | XH2.54 4P：5V / GND / TX / RX |
| 灯带接口 | XH2.54 3P：5V / DIN / GND，DIN 串 330Ω，5V 并 1000µF |
| 蜂鸣器 | AO3400 + 10k 下拉 + 2P 接口 |
| 电池检测 | 100k/100k 分压到 GPIO0，并 100nF 电容 |
| 指示 | 电源 LED |

### 2.2 设计规则

- 板尺寸建议 ≤ 60 × 50 mm，四角 M3 安装孔。
- 5V 电源线宽 ≥ 0.8 mm（灯带满亮约 1A+），GND 铺铜。
- 2 层板，顶层信号、底层整片 GND。
- ESP32 天线区域下方**不要铺铜、不要走线**，天线朝外壳外侧。
- 丝印标清每个接口的线序。

### 2.3 下单

嘉立创 EDA 专业版 → 生成 Gerber → 嘉立创下单，5 片打样通常有优惠；需要贴片时导出 BOM 和坐标文件，器件尽量选嘉立创基础库。

## 3. 外壳与安装

### 3.1 灯头模块（3D 打印）

- 形状：一个套在锥桶顶部开口上的“帽子”，内径按锥桶顶部外径（常见约 5～6 cm）测量。
- 结构：
  - 上层：电池仓 + PCB；
  - 正面：雷达窗口（雷达前方**不能有金属**，可以是 1～2 mm 塑料，PETG/ABS 对 24GHz 衰减小）；
  - 侧面：Type-C 充电口、开关；
  - 下沿：灯带卡槽，外罩透明 PETG 或亚克力条。
- 材料：PETG（耐晒耐温）优于 PLA。
- 防水：接缝处用硅胶条，开口朝下，出线处用防水接头或热熔胶。

### 3.2 雷达安装

- 离地约 0.6～0.8 m（锥桶顶部高度即可）；
- 天线面垂直地面、正对来车方向，可略向下倾 3～5°；
- 哨兵锥桶放在路肩或作业区上游边线，雷达朝向上游车流方向，检测角度覆盖本车道。

### 3.3 工人报警器

小盒子（约 50×35×20 mm），背面魔术贴，或做成夹子夹在反光背心上，马达贴紧盒子底面。

## 4. 进阶

- 加太阳能板（6V 1W）+ CN3791 MPPT 充电，实现长期免维护。
- 加光敏电阻（GPIO 空余 ADC），自动夜间模式。
- 灯带改为 12V 高亮 LED + PWM，提高白天可见度。
