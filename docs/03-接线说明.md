# 接线说明

> 通用原则：**所有模块共地（GND 连在一起）**；雷达和灯带用 5V，ESP32-C3 IO 是 3.3V；避开 ESP32-C3 的启动引脚 GPIO2 / GPIO8 / GPIO9。不同厂家的 C3 板丝印可能不同，以板子引脚图为准。

对照乐鑫 [ESP32-C3 硬件设计指南](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32c3/schematic-checklist.html) 与 [GPIO 说明](https://docs.espressif.com/projects/esp-idf/en/v5.3.5/esp32c3/api-reference/peripherals/gpio.html)（2026-11 核对）：

- 启动脚是 **GPIO2 / GPIO8 / GPIO9**。GPIO0 不是启动脚，复位后为高阻，用作 ADC1_CH0 测电池分压不会改变启动模式。电池脚旁建议加 100 nF 到地（见结构文档）。
- UART0 是 **GPIO20（U0RXD）/ GPIO21（U0TXD）**。GPIO1 不是串口，工人报警器按键可以接它。
- GPIO0、GPIO1 也是可选 32.768 kHz 晶振脚。下面的接法按**没有外接这颗晶振**的 ESP32-C3 开发板（如 ESP32C3 Dev Module）编写。板上若已经焊了 32 kHz 晶振，这两脚不能再当 ADC 和按键。
- 芯片只有 UART0 和 UART1。雷达占用 UART1（GPIO6/7）后，ASRPRO 只能用 UART0；日志改走 USB，所以必须打开 USB CDC On Boot（Arduino IDE 里 “USB CDC On Boot: Enabled”，arduino-cli 用 `--fqbn esp32:esp32:esp32c3:CDCOnBoot=cdc`）。
- 引脚定义写在各 `.ino` 开头的 `#define PIN_*` 里，本文与代码一致；改接线时两边一起改。

## 1. 电源部分（每个锥桶通用）

```
 18650 ──► TP4056(B+ B-) ──OUT+/OUT-──► 开关 ──► 升压模块 IN
                                                    │
                                          升压 OUT 5V（调到 5.0V）
                                                    │
               ┌────────────┬───────────┬──────────┴─────────┐
               ▼            ▼           ▼                    ▼
        ESP32-C3 5V    雷达 5V     灯带 5V(并 1000µF)   ASRPRO 5V
```

- 升压模块先**单独上电用万用表调到 5.0V** 再接负载。
- 电池电压检测：电池正极（TP4056 OUT+）→ 100kΩ → **GPIO0** → 100kΩ → GND。

                ┌──────────────────────┐
  LD2451 TX ───►│ GPIO6            5V  │◄── 5V
  LD2451 RX ◄───│ GPIO7            GND │◄── GND（共地）
  ASRPRO TX ───►│ GPIO20               │
  ASRPRO RX ◄───│ GPIO21               │

| 外设 | ESP32-C3 | 备注 |

| 振动马达 MOSFET 栅极 | GPIO4 | 马达两端反并 1N4148 续流二极管 |

振动马达接法：`3.3V/电池 → 马达+ ; 马达− → AO3400 D ; S → GND`，二极管负极接马达+、正极接马达−。

## 5. 网关

只需 USB 供电，无外设。

## 6. ASRPRO 与 L298N 的关系

本项目**不需要 L298N**。如果你想做演示用的“模拟来车”小车，可以复用之前的 ASRPRO + L298N 小车方案（ASRPRO PA5→IN1、PA6→IN2，共地，换向前停 200 ms），让小车冲向锥桶阵列，用于室内演示。

## 7. 常见接线错误

| 现象 | 原因 |
|---|---|
| 雷达无数据 | TX/RX 接反；供电不足（用了 3.3V） |
| 灯带乱色/第一颗不亮 | 没共地；没串电阻；数据线太长 |
| 一开蜂鸣器就重启 | 电源电流不够，加大电容或换 2A 升压 |
| 下载失败 | GPIO9 被外设拉低；ASRPRO TX 干扰，先拔掉 |
