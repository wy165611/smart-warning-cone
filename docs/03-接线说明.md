# 接线说明

> 通用原则：**所有模块共地（GND 连在一起）**；雷达和灯带用 5V，ESP32-C3 IO 是 3.3V；避开 ESP32-C3 的启动引脚 GPIO2 / GPIO8 / GPIO9。不同厂家的 C3 板丝印可能不同，以板子引脚图为准。

## 1. 电源部分（每个锥桶通用）

```
 18650 ──► TP4056(B+ B-) ──OUT+/OUT-──► 开关 ──► 升压模块 IN
                                                    │
                                          升压 OUT 5V（调到 5.0V）
                                                    │
               ┌────────────┬───────────┬──────────┴─────────┐
               ▼            ▼           ▼                    ▼
        ESP32-C3 5V    雷达 5V     灯带 5V(并 1000µF)   ASRPRO 5V
```

- 升压模块先**单独上电用万用表调到 5.0V** 再接负载。
- 电池电压检测：电池正极（TP4056 OUT+）→ 100kΩ → **GPIO0** → 100kΩ → GND。

## 2. 哨兵锥桶

| 外设 | 外设引脚 | ESP32-C3 | 备注 |
|---|---|---|---|
| LD2451 雷达 | 5V | 5V | 需 >200 mA |
| | GND | GND | |
| | TX | **GPIO6** | UART1 RX |
| | RX | **GPIO7** | UART1 TX |
| WS2812 灯带 | 5V | 5V | 电源端并联 1000µF |
| | GND | GND | |
| | DIN | **GPIO10** | 串 330Ω |
| 蜂鸣器 | + | 5V | |
| | − | AO3400 漏极 D | |
| AO3400 | 栅极 G | **GPIO3** | G 与 GND 间接 10kΩ 下拉 |
| | 源极 S | GND | |
| ASRPRO | TX | **GPIO20** | UART0 RX，9600 |
| | RX | **GPIO21** | UART0 TX |
| | 5V / GND | 5V / GND | |
| 电池分压 | 中点 | **GPIO0** | 100k/100k |

```
                ┌──────────────────────┐
  LD2451 TX ───►│ GPIO6            5V  │◄── 5V
  LD2451 RX ◄───│ GPIO7            GND │◄── GND（共地）
  ASRPRO TX ───►│ GPIO20               │
  ASRPRO RX ◄───│ GPIO21               │
  WS2812 DIN ◄──│ GPIO10 ─[330Ω]       │
  AO3400 G  ◄───│ GPIO3                │
  分压中点  ───►│ GPIO0   ESP32-C3     │
                └──────────────────────┘
```

> 说明：ESP32-C3 的日志走板载 USB（Arduino 中打开 “USB CDC On Boot”），因此 UART0 可以留给 ASRPRO。烧录时若出现异常，可先断开 ASRPRO 的 TX 线。

## 4. 工人报警器

| 外设 | ESP32-C3 | 备注 |
|---|---|---|
| 振动马达 MOSFET 栅极 | GPIO4 | 马达两端反并 1N4148 续流二极管 |
| 蜂鸣器 MOSFET 栅极 | GPIO3 | |
| 红色 LED（串 220Ω） | GPIO5 | |
| 按键（另一端接 GND） | GPIO1 | 内部上拉 |
| 电池分压 | GPIO0 | |

振动马达接法：`3.3V/电池 → 马达+ ; 马达− → AO3400 D ; S → GND`，二极管负极接马达+、正极接马达−。

## 5. 网关

只需 USB 供电，无外设。

## 6. ASRPRO 与 L298N 的关系

本项目**不需要 L298N**。如果你想做演示用的“模拟来车”小车，可以复用之前的 ASRPRO + L298N 小车方案（ASRPRO PA5→IN1、PA6→IN2，共地，换向前停 200 ms），让小车冲向锥桶阵列，用于室内演示。

## 7. 常见接线错误

| 现象 | 原因 |
|---|---|
| 雷达无数据 | TX/RX 接反；供电不足（用了 3.3V） |
| 灯带乱色/第一颗不亮 | 没共地；没串电阻；数据线太长 |
| 一开蜂鸣器就重启 | 电源电流不够，加大电容或换 2A 升压 |
| 下载失败 | GPIO9 被外设拉低；ASRPRO TX 干扰，先拔掉 |
