# 从零开始搭建指南

按顺序做，每一步都有“成功标志”，没达到就不要往下走。

## 第 0 步：准备

- 电脑：Windows / macOS 均可。
- 软件：Arduino IDE 2.x、Python 3.10+、天问 Block（ASRPRO 用）、Git。
- 器件：按 `02-物料清单BOM.md` 采购。

## 第 1 步：安装 Arduino 开发环境

1. 安装 Arduino IDE 2.x。
2. 文件 → 首选项 → “附加开发板管理器网址”填：
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
3. 工具 → 开发板 → 开发板管理器，搜索 **esp32**（Espressif Systems），安装 **3.x 版本**（本项目回调函数按 3.x 写）。
4. 工具 → 管理库，安装：
   - **Adafruit NeoPixel**
   - **PubSubClient**（仅网关）
5. 板卡设置：开发板选 **ESP32C3 Dev Module**，**USB CDC On Boot: Enabled**，端口选对应 COM。

**成功标志**：烧录“文件→示例→01.Basics→Blink”不报错。

> 也可以用命令行编译。2026-11-03 用 arduino-cli 1.5.1 和核心 3.3.12 编过四个草图，`--warnings all` 无警告：
>
> ```bash
> arduino-cli core install esp32:esp32@3.3.12
> arduino-cli lib install "Adafruit NeoPixel" PubSubClient
> arduino-cli compile --fqbn esp32:esp32:esp32c3:CDCOnBoot=cdc firmware/sentinel
> ```

## 第 2 步：单独测试雷达（电脑直连）

1. USB-TTL 与雷达接线：5V→5V，GND→GND，TX→雷达RX，RX→雷达TX。
2. `pip install pyserial`
3. `python tools/radar_monitor.py COM5`（换成你的串口）
4. 拿雷达对着走廊/路边，人走动或车经过。

**成功标志**：屏幕打印 `角度 +3° 距离 25m 靠近 32km/h`。

> 也可以用海凌科官方手机 App（蓝牙）调雷达最远距离、方向、灵敏度。建议设为“只检测靠近”、最远 100 m、最低速度 5 km/h。

## 第 3 步：哨兵单节点

1. 按 `03-接线说明.md` 接好雷达、灯带、蜂鸣器（先不接 ASRPRO）。
2. 用 Arduino IDE 打开 `firmware/sentinel/sentinel.ino`（目录内已附 config.h、protocol.h、ld2451.h、kalman.h）。
3. 参数只改 `firmware/common/config.h`，再运行 `python tools/sync_common.py` 同步到四个草图目录（`pytest` 会检查副本是否一致）。`WIFI_CHANNEL` 先用 6，后面网关环节再统一。
4. 上传，打开串口监视器 115200。

**成功标志**：上电灯带红闪 3 下（自检）→ 黄灯慢闪；有人/车靠近时串口打印 `[RADAR] d=… v=… ttc=… level=…`，灯光随等级变化；目标离开约 1.5 s 后回到黄灯慢闪（拔掉雷达 TX 线也应如此）。

调试技巧：室内测试时，可把 `config.h` 中 `MIN_TRACK_SPEED` 改成 2，人快走也能触发。

## 第 4 步：联动锥桶

1. 打开 `firmware/follower/follower.ino`，把 `NODE_ID` 改成 2，上传到第二块板；第三块改成 3。
2. 所有节点 `WIFI_CHANNEL` 必须一致。

**成功标志**：哨兵进入一级预警时，联动锥桶出现流水灯；二级时全部红色爆闪。

## 第 5 步：工人报警器

上传 `firmware/worker/worker.ino`。

**成功标志**：二级预警时马达连续震动、蜂鸣；按键后 10 秒内只震不响。

## 第 6 步：ASRPRO 语音

1. 按 `asrpro/README.md` 安装天问 Block，导入 `asrpro_sentinel.c`，编译下载。
2. 接 ASRPRO 与哨兵的串口（交叉接 TX/RX，共地）。

**成功标志**：说“小哨兵”→“开始作业”，听到播报，哨兵串口打印 `[VOICE] cmd=0x01`；说“左侧封道”，联动锥桶流水灯方向改变（离哨兵较远、只能收到中继的锥桶也应改变）。

## 第 7 步：网关与服务器

1. 路由器后台把 2.4G 信道**固定**为某个值（如 6），所有节点的 `WIFI_CHANNEL` 填同一个值并重新烧录。
2. 在电脑上启动服务器（二选一）：
   - **Docker**：`cd server && docker compose up -d`
   - **本地**：安装 Mosquitto（Windows 下载安装包，macOS `brew install mosquitto`，并允许匿名）；不想装也可以用纯 Python 的 `pip install amqtt` 然后运行 `amqtt` 当临时 MQTT 服务器。然后
     `cd server && pip install -r requirements.txt && python app.py`
3. 查看电脑局域网 IP，填入 `config.h` 的 `MQTT_HOST`，以及 `WIFI_SSID / WIFI_PASS`，上传 `firmware/gateway/gateway.ino`。
4. 浏览器打开 `http://localhost:8000`。

**成功标志**：看板中出现各锥桶在线与电量；有车靠近时曲线实时变化，车辆通过后事件列表新增一行。

> 没有硬件时，先运行 `python tools/simulator.py` 就能看到看板效果。

## 第 8 步：装进锥桶

1. 按 `09-PCB与外壳设计.md` 打 PCB 或焊洞洞板，装入 3D 打印灯头。
2. 雷达天线面朝来车方向，离地约 0.6～0.8 m，略微向下倾斜 3～5°，避免打到远处护栏。
3. 灯带绕锥桶上部一圈，外面可罩一层透明 PETG/亚克力防护。

## 第 9 步：测试与录视频

按 `07-测试方案与数据记录表.md` 做测试，按 `08-演示与答辩脚本.md` 录视频。

## 常见问题

| 问题 | 解决 |
|---|---|
| 编译报 `esp_now_recv_info_t` 未定义 | ESP32 开发板包版本是 2.x，升级到 3.x |
| 联动锥桶收不到 | 信道不一致；网关连上路由器后信道变了，固定路由器信道 |
| 雷达在室内乱报 | 墙面多径反射，属正常，户外测试；或在 App 中调高灵敏度阈值 |
| 灯带太暗 | 提高 `LED_BRIGHTNESS`，同时确认升压模块电流够 |
| 网页“后端未连接” | `python app.py` 是否在运行，防火墙是否放行 8000 端口 |
