## 一、项目摘要（约 300 字）

公路养护作业区是道路交通安全的薄弱环节，作业人员被闯入车辆撞伤、施工区追尾等“二次事故”时有发生。传统作业区依赖锥桶、标志牌等被动设施，无法感知来车风险，也无法在危险发生前提醒司机和工人。

本项目研制“哨兵”智能预警锥桶系统：在作业区上游布设搭载 24GHz 毫米波雷达的哨兵锥桶，实时测量来车速度与距离，计算碰撞时间（TTC）并进行分级预警；多个锥桶通过 ESP-NOW 自组网联动，形成“流水灯”引导车辆提前变道；工人佩戴报警器，在高危时刻震动提醒撤离；作业人员可用离线语音快速部署与切换模式；全部预警与危险接近事件经网关上传云平台，生成作业区安全报告。

系统单个哨兵节点成本约 100 元，一套 3～5 个锥桶的作业区系统约 200～300 元，远低于现有进口作业区预警设备，具备在县乡公路、城市道路养护中大规模推广的潜力。

**关键词**：公路养护；作业区安全；毫米波雷达；碰撞时间；物联网；协同预警

## 二、项目背景与意义

### 2.1 现实问题

1. **作业区事故后果严重**。公路养护多在不封闭交通的情况下进行，车辆高速闯入作业区，伤及工人和设备，事故后果往往比普通事故严重。【填：引用交通运输部或学术文献中关于作业区事故的统计数据】
2. **传统安全设施是“被动”的**。锥桶、水马、标志牌只能隔离和提示，无法判断某辆车是否超速、是否在接近作业区却没有减速。
3. **工人背对来车，感知滞后**。作业时工人注意力在路面上，噪声大，往往在车辆接近时才发现危险，撤离时间不足。
4. **现有智能设备贵、部署难**。市场上的作业区预警系统、防撞缓冲车价格高，多用于高速公路大型作业，县乡道路、城市道路的日常小型养护很难配备。
5. **缺乏数据**。养护单位无法量化“作业区到底有多危险”，安全管理凭经验，难以持续改进。

### 2.2 政策契合

| 政策 | 本项目的回应 |
|---|---|
| 《交通强国建设纲要》提出构建安全、便捷、高效、绿色、经济的现代化综合交通体系 | 以低成本智能设备提升公路“平安交通”水平 |
| 交通运输部《关于推进公路数字化转型 加快智慧公路建设发展的意见》 | 作业区状态、来车速度、危险事件数字化采集与上云 |
| 安全生产治本攻坚三年行动（2024—2026 年） | 从“被动防护”到“主动预警”，从源头降低养护作业风险 |
| 国务院关于深入实施“人工智能+”行动的意见 | 边缘端实时智能判断，让传统交通设施“有感知、会思考” |

### 2.3 项目意义

- **保护生命**：在碰撞前 2.5～5 秒提醒司机与工人，为减速和撤离争取时间。
- **降本普惠**：百元级成本，让县乡道路小型养护也用得起智能预警。
- **数据赋能**：量化作业区风险，为养护单位安全管理、交管部门执法提供依据。

| 类型 | 典型形式 | 不足 |

## 四、项目内容与技术方案

### 4.1 系统总体架构

系统由四类节点和一个平台组成：

1. **哨兵锥桶**（作业区最上游 50～150 m）：毫米波雷达测速测距，TTC 分级判断，声光预警，向全网广播。
2. **联动锥桶**（沿上游过渡区布设）：接收预警，按位置顺序点亮形成流水灯，引导车辆变道。
3. **工人报警器**（佩戴）：二级预警时强震动 + 蜂鸣，提示撤离。
4. **网关**：把 ESP-NOW 数据转为 MQTT 上传。
5. **安全管理平台**：实时看板、事件记录、作业区安全报告。

（架构图见 README，答辩 PPT 中替换为美化后的示意图）

### 4.2 硬件设计

| 模块 | 方案 | 选型理由 |
|---|---|---|
| 主控 | ESP32-C3 | 低功耗 RISC-V，自带 Wi-Fi/BLE，支持 ESP-NOW，价格约 12 元 |
| 感知 | HLK-LD2451 24GHz FMCW 雷达 | 专为车辆检测设计，最远约 100 m，输出速度、距离、方向、角度，全天候工作 |
| 预警 | WS2812 灯带 + 蜂鸣器/喇叭 | 可编程多色闪烁，实现分级与流水灯 |
| 语音 | ASRPRO 离线语音模块 | 无网络也能识别，工人不需看屏幕 |
| 电源 | 18650 锂电 + TP4056 + 升压，可加太阳能板 | 野外独立供电 |
| 结构 | 3D 打印灯头模块，卡装在标准锥桶顶部 | 不改变现有锥桶，兼容性好 |

### 4.3 核心算法

1. **雷达数据滤波**：一维卡尔曼滤波平滑距离与速度，抑制跳变。
2. **碰撞时间计算**：TTC = 距离 ÷ 接近速度。
3. **分级预警**：
   - 安全：黄灯慢闪；
   - 一级：TTC < 5 s 或超作业区限速 20%，红黄快闪 + 流水灯；
   - 二级：TTC < 2.5 s，红色爆闪 + 蜂鸣 + 工人震动。
4. **自适应阈值**：雨天模式阈值 ×1.4，夜间模式 ×1.2，兼顾路面湿滑制动距离变长、夜间反应时间变长。
5. **防误报**：连续 3 帧满足才升级；只追踪接近方向目标；过滤低速与超远目标；目标消失后保持 1.5 s 再解除。
6. **多目标选择**：同时检测多个目标时，选取 TTC 最小的“最危险目标”。

### 4.4 组网与通信

- 节点间采用 **ESP-NOW** 广播：无需路由器、延迟低（毫秒级）、免费。
- 包含序号去重、最多 2 跳中继，扩大覆盖距离。
- 网关经 Wi-Fi 接入 MQTT 服务器，平台订阅入库。

### 4.5 软件平台

- 后端：Python FastAPI + SQLite + MQTT。
- 前端：网页看板，显示锥桶在线状态、电量、实时车速与 TTC 曲线、危险事件列表、自动生成的安全报告。

## 五、创新点

1. **从“被动隔离”到“主动感知”**：在传统锥桶上加装百元级雷达模块，让作业区第一次“看得见”来车风险。
2. **基于 TTC 的分级预警与自适应阈值**：按危险程度分别提醒司机与工人，并根据雨天、夜间自动调整，避免“一直闪、没人看”。
3. **锥桶协同组网与流水灯引导**：多个锥桶自组网联动，用动态灯光引导变道，比单点爆闪更醒目。
4. **工人端主动撤离提醒**：震动 + 声音直达工人身上，弥补工人背对来车的感知盲区。
5. **离线语音快速部署**：作业人员戴手套、在路上也能一句话完成部署和模式切换。
6. **作业区安全数据化**：首次以低成本方式量化作业区“危险接近”事件，为安全管理提供数据支撑。

## 十二、风险与对策

| 风险 | 对策 |
|---|---|
| 雷达受护栏、路牌反射产生虚警 | 限定角度与距离窗口、只追踪接近目标、连续帧确认 |

| 电池续航不足 | 无车时降低刷新率、太阳能补电 |
| 无线干扰导致联动失败 | 序号去重、重复广播、多跳中继、离线自主闪烁 |
| 测试安全 | 只在封闭场地低速测试，使用电动车或遥控车模拟 |
