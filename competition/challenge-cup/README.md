# 挑战杯申报材料

第二十届“挑战杯”全国大学生课外学术科技作品竞赛 · 科技发明制作类（B 类）。

| 文件 | 说明 |
|---|---|
| `哨兵_挑战杯作品申报书.docx` | 申报书（A 申报者情况、B3 作品情况、C 推荐者情况）+ 附件研究报告 |
| `哨兵_挑战杯答辩PPT.pptx` | 答辩 PPT，22 页，每页有讲稿备注 |
| `facts.py` | 两份文件共用的数字和参考文献，**改数字只改这里** |
| `figs.py` | 生成 `img/` 下的架构图、布设图、TTC 判定图、理论时间窗图、仿真曲线 |
| `gen_docx.py` / `gen_ppt.py` | 生成 docx / pptx |

## 重新生成

```bash
pip install -e ".[competition]"     # 在仓库根目录执行
make -C competition/challenge-cup    # 或 make competition
make -C competition/challenge-cup pdf  # 需要 LibreOffice，PDF 输出到 build/（不入库）
```

## 写作规则

- 每个数字都要能在仓库代码（`firmware/common/config.h`、`tests/`）或 `facts.py` 里列出的公开资料中找到，
  参考文献都已逐条打开核对。
- 没有实测或调研依据的内容写成黄色底纹的【待补充：…】【待实测】【填】【请核对】，**不要估填**。
- 不写“国内首次”“填补空白”这类无法证明的说法；作业区入侵报警、顺序警示灯在国外已有应用，本作品定位是低成本集成。
- `img/hero_cone.png`、`img/workzone.png` 是 AI 生成的概念图，正式提交前换成团队实拍照片；
  `img/dashboard_sim.png` 是模拟器数据的看板截图，不是实测。

## 提交前需要团队补齐

1. 团队成员、指导教师、学校学院（当前“山东理工大学 交通与车辆工程学院”沿用仓库初稿，请核对）。
2. 我国作业区事故统计或典型案例（附官方出处）。
3. 国内相关文献与在售产品的名称、参数、价格。
4. 实际采购价、实物样机照片、封闭场地实测数据（申报书表 6 / PPT 第 16 页）。
5. 专利、软著、获奖情况（没有就写“暂无”）。
